# Laboratório de Cibersegurança — Kali Linux e Medusa

## Sobre o projeto

Este projeto apresenta a implementação de um laboratório prático de cibersegurança utilizando Kali Linux, Medusa e ambientes vulneráveis para simular cenários controlados de ataques de força bruta e estudar medidas de prevenção e mitigação.

## Objetivos

- Compreender o funcionamento de ataques de força bruta.
- Explorar a ferramenta Medusa.
- Realizar testes controlados em serviços vulneráveis.
- Analisar os resultados obtidos.
- Identificar vulnerabilidades e propor medidas de mitigação.

## Ambiente utilizado

- Kali Linux
- Metasploitable 2
- DVWA (Damn Vulnerable Web Application)
- Oracle VirtualBox
- Medusa

## Cenários de testes

1. Testes de autenticação no serviço FTP.
2. Simulação de tentativas automatizadas em formulário web utilizando DVWA.
3. Estudo de Password Spraying e enumeração de usuários em SMB.

## Documentação dos experimentos

Os procedimentos, comandos, evidências e resultados de cada cenário serão apresentados nas respectivas seções deste repositório.

## Considerações sobre segurança

Todos os testes são realizados em ambiente de laboratório controlado, com finalidade exclusivamente educacional.
